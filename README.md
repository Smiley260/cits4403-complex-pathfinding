# cits4403-complex-pathfinding
Analysis of ant colony optimisation as a comparison to deterministic algorithms for pathfinding in a dynamic network

# Research question:
In the case of a dynamically weighted network as the rate of change of the network weights fluctuates, will an ant colony approach to pathfinding become more efficient than a deterministic approach to pathfinding such as A*?

## Running the model
Please ensure that you run the jupyter notebook server from either the project root (cits4403-complex-pathfinding) or from within the notebooks folder as the python script interacts with the OS file system and will fail if the jupyter notebook server is not running fro, one of the specified directories.
